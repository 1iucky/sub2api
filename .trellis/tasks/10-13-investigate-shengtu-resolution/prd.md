# 排查 shengtu 生图尺寸仅返回 2K

## Goal

确定已安装 shengtu-skill 对接 siliconbase.link 时，图片仅返回 2K 的现象发生在客户端参数、平台转发配置还是上游模型。

## Requirements

- R1：用户指定模型 `gpt-image-2.5`，首先验证网关是否接受该名称。
- R2：用户已授权自行调用生图接口，对比不同尺寸、质量和 PNG/JPEG/WebP 格式，读取文件真实像素。
- R3：使用已安装脚本及其专用生图密钥，不读取或修改全局认证，不在记录中输出密钥。
- R4：核对当前仓库的尺寸解析、模型映射、OAuth/API Key 转发与输出保存逻辑。
- R5：形成包含请求参数、实际输出、可复核证据与未验证边界的结论。

## Acceptance Criteria

- [x] 记录实际模型名称、请求尺寸/格式/质量和返回文件像素或错误。
- [x] 区分计费档位和文件真实分辨率。
- [x] 结论区分已证实原因与尚需服务端证据的假设；详见 research/report.md。

## Notes

本任务为诊断研究，不修改 skill、业务代码或线上配置。若需要修复，先给出基于证据的方案。本阶段不进入业务实现。
